# Датасет классификации цен на мобильные телефоны (Mobile Price Classification)

Этот набор данных предназначен для оценки и прогнозирования ценового диапазона мобильных телефонов на основе их технических характеристик.

## Структура файлов
- `train_ru.csv`: Обучающая выборка (2000 строк). Заголовки переведены на русский язык, числовые значения сохранены (готов к обучению моделей машинного обучения).
- `test_ru.csv`: Тестовая выборка (1000 строк).
- `train_ru_opisanie.csv`: Наглядная версия с текстовыми значениями (например, "Есть"/"Нет", "Низкая цена", "Средняя цена" и т.д.) для разведочного анализа данных (EDA).

---

## Описание признаков (Словарь данных)

| Название столбца | Исходное название (EN) | Единицы / Значения | Описание |
| :--- | :--- | :--- | :--- |
| `emkost_batarei_mach` | `battery_power` | мАч | Полная емкость аккумулятора в мАч |
| `bluetooth` | `blue` | 0 = Нет, 1 = Есть | Наличие модуля Bluetooth |
| `taktovaya_chastota_ggts` | `clock_speed` | ГГц | Тактовая частота микропроцессора |
| `dve_sim_karty` | `dual_sim` | 0 = Нет, 1 = Есть | Поддержка двух SIM-карт |
| `front_kamera_mp` | `fc` | Мп | Разрешение фронтальной (селфи) камеры |
| `four_g` | `four_g` | 0 = Нет, 1 = Есть | Поддержка сотовой связи 4G |
| `vstroennaya_pamyat_gb` | `int_memory` | ГБ | Объем встроенной постоянной памяти |
| `tolschina_sm` | `m_dep` | см | Толщина корпуса телефона |
| `ves_telefona_gr` | `mobile_wt` | г | Вес телефона в граммах |
| `kolichestvo_yader` | `n_cores` | шт. | Количество ядер центрального процессора |
| `osnovnaya_kamera_mp` | `pc` | Мп | Разрешение основной (задней) камеры |
| `vysota_razresheniya_px` | `px_height` | пикс. | Разрешение экрана по высоте |
| `shirina_razresheniya_px` | `px_width` | пикс. | Разрешение экрана по ширине |
| `ram_mb` | `ram` | МБ | Объем оперативной памяти (ОЗУ) |
| `vysota_ekrana_sm` | `sc_h` | см | Физическая высота экрана |
| `shirina_ekrana_sm` | `sc_w` | см | Физическая ширина экрана |
| `vremya_razgovora_ch` | `talk_time` | часы | Максимальное время разговора от одной зарядки |
| `three_g` | `three_g` | 0 = Нет, 1 = Есть | Поддержка сотовой связи 3G |
| `sensornyy_ekran` | `touch_screen` | 0 = Нет, 1 = Есть | Наличие сенсорного дисплея |
| `wifi` | `wifi` | 0 = Нет, 1 = Есть | Наличие модуля Wi-Fi |
| `diapazon_cen` | `price_range` | 0, 1, 2, 3 | **Целевая переменная:**<br>0: Низкая стоимость<br>1: Средняя стоимость<br>2: Высокая стоимость<br>3: Очень высокая стоимость |
